## Pedido
El diseño y concepto visual del usuario están aprobados. NO replantear estética, mensajes o acción. Trabajar sobre `index.html` y `assets/`. La versión autocontenida es `DEMOSTRACION-INTERACTIVA.html`. El Reel de referencia es `REEL-9x16.mp4`.

## Idea visual aprobada
Calle de **arena y pinos**, arquitectura baja residencial, ambiente de Villa Gesell. Oscuro: silueta que parece encapuchada con perro y **se acerca a cámara**. Con iluminación LED: descubrimos a una **mujer de pelo largo y perro normal alejándose de cámara**. El encendido presenta el descubrimiento. Las dos imágenes ya están creadas y provistas. Usarlas sin regenerarlas ni agregar objetos nuevos.

## Texto institucional exacto
> La Municipalidad de Villa Gesell compró nuevas luminarias LED.

No incluir cantidades, barrios, fecha de instalación ni potencia de equipos hasta confirmación documental. Al cierre: «PARA QUE VEAS MEJOR. UNA GESTIÓN QUE SE VE.»

## Interactivo web
- El HTML incluido ya tiene animación de encendido y botón para repetir, probados en móvil y escritorio.
- Mantener la sorpresa; mostrar la escena iluminada antes de introducir los datos institucionales.
- **No rehacer logos municipales ni símbolos de memoria.** Solo usar un logo oficial si el municipio lo provee expresamente.
- Modal embebible para CMS municipal: sumar cierre, `Escape`, comportamiento de frecuencia y control de accesibilidad cuando se integre, sin alterar el diseño aprobado.
- Optimización responsive y peso razonable, sin librerías obligatorias.
- En celulares, NO superponer el copy sobre la mujer y el perro. El estado de revelación actual ubica el texto arriba y la escena abajo.
- La imagen de referencia es **ilustrativa**, no una foto real de una cuadra identificada; reemplazar por locación real solo si se aportan archivos oficiales.
- La transición es un **montaje de dos ángulos narrativos**, no el mismo fotograma aclarado. Que el efecto de luz disimule con elegancia el cambio; no representar que se transformó una persona.
